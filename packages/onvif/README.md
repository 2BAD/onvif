# @2bad/onvif

Core of the `@2bad/onvif` ONVIF client. SOAP parsing and serialization, WS-Security, HTTP transport with Digest auth and TLS pinning, typed errors. No runtime deps.

> [!WARNING]
> Still in development, not usable yet. Check the [repo](https://github.com/2BAD/onvif) for status.
